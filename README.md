# مسار نجران | Najran Transit — النسخة 2.0 (بروتوتايب)

تطبيق راكب تجريبي لنموذج **حافلات ترددية بين محطات ثابتة على مسارات معلنة**، مع الدفع عند الصعود بالمحفظة.
كل الحركة وأوقات الوصول والمدفوعات **محاكاة** لأغراض العرض أمام لجنة NEXUS.

## التشغيل محليًا

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # نسخة إنتاج في dist/
npm run preview      # معاينة نسخة الإنتاج على http://localhost:4173
```

الاختبار الشامل لمسار العرض (يتطلب Playwright مثبتًا):

```bash
npm run build && npx vite preview --port 4173 &
npm run test:e2e     # SHOTS=./shots لحفظ لقطات الشاشة
```

## النشر لاحقًا (Vercel)

المشروع Vite + React مثل النسخة السابقة؛ إعدادات Vercel الافتراضية تعمل كما هي:
Build Command `npm run build` ، Output Directory `dist`.
لم يُنشر شيء على https://najran-transit.vercel.app/ — النشر بقرارك:
ارفع الملفات إلى مستودع المشروع المرتبط بـ Vercel، أو من جهازك: `npx vercel --prod`.

## ما الذي تغيّر

**أُزيل:** الخطوط الثلاثة (الأخضر/الأحمر/الأزرق) وتصنيفاتها وألوانها؛ مسح QR كشرط للدفع المسبق؛
روابط «الإعدادات/الإشعارات/المساعدة» التي لا تعمل؛ تحميل المسار من خدمة توجيه خارجية أثناء العرض.

**تغيّر:**
- الرئيسية: خريطة نجران مع 8 محطات ثابتة قابلة للنقر، بحث «إلى أين تريد الذهاب؟»، اختيار محطة الانطلاق،
  الحافلتان القادمتان بوقت تجريبي، تحديد الموقع اختياري، زر «عرض الرحلات».
- الرحلات: رحلات مباشرة من المسارات المعلنة فقط، وحالة «لا توجد رحلة مباشرة في النموذج التجريبي».
- تفاصيل الرحلة: التتبع داخل الصفحة نفسها (خريطة + محطات متسلسلة + وقت كل محطة)، «محاكاة وصول الحافلة»،
  ثم «الدفع عند الصعود»، ثم «محاكاة الوصول إلى الوجهة».
- المحفظة: رصيد، شحن تجريبي (مدى/Visa)، نقاط على الدفع بالمحفظة فقط، استبدال النقاط، سجل العمليات.
- حسابي: إظهار الأسماء الإنجليزية، تكبير النص، تقليل الحركة، سجل الرحلات، «جرّب التطبيق» برمز QR، شرح المحاكاة.
- زر «تجربة العرض» في الشريط العلوي يعيد السيناريو من البداية ويرشد المستخدم خطوة بخطوة.
- الهوية: خلفية #F8FAFC، نص #0F172A، لون أساسي #00C49F، خط Noto Kufi Arabic مضمّن محليًا، RTL.

**بقي من النسخة السابقة:** React + Vite + Leaflet/OpenStreetMap، التنقل بأربعة تبويبات، منطق المحفظة
(أجرة 4 ر.س، 10 نقاط للرحلة، 100 نقطة = 5 ر.س)، الشاشة الافتتاحية «نجران تتحرك معك».

## تعديل البيانات (دون تعديل الشاشات)

| الملف | المحتوى |
|---|---|
| `src/data/stations.js` | المحطات: الاسم، الاسم الإنجليزي، الإحداثيات، معلومات الوصول |
| `src/data/services.js` | المسارات: الرقم، الاسم، تسلسل المحطات |
| `src/data/vehicles.js` | الحافلات التجريبية وموضعها الابتدائي |
| `src/data/config.js` | الأجرة، النقاط، مبالغ الشحن، متوسط السرعة، رابط التطبيق |
| `src/data/routeGeometry.json` | خطوط المسارات على الطرق (مولّدة) |

بعد تعديل تسلسل محطات أي مسار: `NODE_USE_ENV_PROXY=1 npm run geometry` (أو `npm run geometry` دون بروكسي)
لإعادة رسمه على الطرق عبر OSRM. إن لم يُعَد الرسم، يظهر المسار خطًا متقطعًا تقريبيًا ولا تتحرك عليه حافلة.

## ما هو محاكاة وما يحتاج تشغيلًا حقيقيًا

| العنصر | في البروتوتايب | للتشغيل الحقيقي |
|---|---|---|
| مواقع الحافلات | محسوبة من ساعة محاكاة ومتوسط سرعة 40 كم/س | أجهزة تتبع AVL/GPS في الحافلات وخادم بيانات لحظية |
| أوقات الوصول | تقديرية من الموضع المحاكى | نموذج تنبؤ من بيانات التتبع والحركة المرورية |
| المحطات | مواقع توضيحية قرب معالم من OpenStreetMap | مواقع معتمدة من الجهة المشغلة والبلدية |
| المسارات | مرسومة آليًا على شبكة الطرق (OSRM) وغير معتمدة | تخطيط تشغيلي معتمد وجداول رسمية |
| الأجرة | 4 ر.س افتراضية | تسعيرة معتمدة |
| المحفظة والشحن والدفع | في المتصفح فقط (localStorage) | بوابة دفع مرخّصة، حسابات مستخدمين، أجهزة تحقق في الحافلات |
| رمز QR | يفتح رابط النموذج فقط | — |

## رمز QR

`public/qr/najran-transit-app-qr.png` (1200×1200) و`.svg` — يفتح https://najran-transit.vercel.app/ ،
تصحيح أخطاء M، منطقة هادئة 4 وحدات، بلا شعار في المنتصف. تم التحقق من فكّه برمجيًا؛ يُنصح بتجربة المسح بكاميرا الهاتف.
يظهر داخل التطبيق في «حسابي ← جرّب التطبيق».

## ملاحظة عن المصدر

لم يكن مستودع النسخة السابقة متاحًا، فأُعيد بناء المشروع من الكود المنشور على Vercel (نفس التقنيات)
ثم طُوّر. عند توفر المستودع الأصلي يمكن استبدال محتواه بهذه الملفات.
